# 选号设计全规则

## 选号设计与算号不同

算号观察：

- 看已有号码。
- 不需要八字。
- 不联网。
- 以固定排盘和结构解释为主。

选号设计：

- 为号主设计候选号码。
- 需要外部 `bazi_yongshen` 或人工提供喜用神。
- 可选联网查公开号段/归属地/可得性线索。
- 不承诺库存，不自动购买。

## 必要输入

```text
出生时间：
出生地：
八字喜用神：
性别：
年龄/阶段：
职业/角色：
选号目标：
当前手机号：
城市：
运营商：
偏好号段：
是否允许联网：
候选数量：
```

如果没有 `八字喜用神`：

- 请求用户提供。
- 或请求用户允许调用外部八字工具。
- 本知识库不能凭空推断喜用神。

## 成年人选号

成年人通常以天医作为收口，强调财库和稳定收益承接。

建议：

- 天医可有一个大组合。
- 前面可配一个小天医形成递进。
- 不要两个大天医重复堆叠。
- 根据职业选择天医前面的动态星。

## 职业组合

| 角色/目标 | 推荐动态 | 示例方向 | 说明 |
|---|---|---|---|
| 销售、表达、讲师 | 祸害 -> 天医 | `713` 类 | 表达成交转财库 |
| 投资、资产、创业魄力 | 绝命 -> 天医 | `213`、`968` 类 | 投入行动被财库承接 |
| 创意、教育、策划 | 五鬼 -> 天医 | `368` 类 | 思考创意转收益 |
| 管理、运营、企业经营 | 延年 -> 天医 | `913`、`786` 类 | 能力管理转收益 |
| 设计、客服、审美服务 | 六煞 -> 天医 | `168`、`386` 类 | 关系审美服务转收益 |
| 贵人来财、资源整合 | 生气 -> 天医 | `413`、`672` 类 | 贵人机会转收益 |

## 老人选号

核心诉求：

- 健康稳定。
- 家庭和睦。
- 少操心。

建议：

- 生气 -> 延年。
- 以小延年或中小延年为主。
- 凶星少配，只做辅助。
- 避免大绝命、大五鬼、大延年过重。
- 不做健康承诺。

## 孩子/学生选号

核心诉求：

- 学习。
- 思考。
- 行动。
- 压力不过载。

建议：

- 小五鬼 -> 延年 -> 生气。
- 男孩可适度大一点。
- 女孩慎用大延年、大绝命、大五鬼。
- 如果孩子现实中已经很努力，不要继续加压。
- 不做学业承诺。

## 女性与大延年

原始材料有“女性禁止大延年”的强说法。

本知识库统一为：

```text
女性、女孩、老人或高压力人群使用大延年要谨慎，需要结合职业、阶段、承压能力和尾部缓冲，不写成一刀切禁令。
```

## 选号禁忌

| 禁忌 | 规则 |
|---|---|
| 0 | 选号尽量避 0，尤其后八位和尾部 |
| 5 夹凶星 | 如 `158/157`，放大风险，规避 |
| 大延年夹 5 | 如 `159/951`，压力放大，慎用 |
| 大天医重复 | `13/31` 与 `68/86` 不要重复堆叠 |
| 凶星连片 | 三颗凶星连在一起规避 |
| 凶星总量 | 建议不超过 3 个，且必须有吉星承接 |
| 凶星结尾 | 绝命、五鬼、祸害、六煞尾部慎用 |
| `95/59` | 只作为补充来源特殊口径，不写入固定真表 |

## 号段与联网边界

补充材料提到偏好号段：

```text
139、136、138、137、135、186、188
```

谨慎号段：

```text
带 0 的号段、147 等
```

处理方式：

- 号段偏好只作为补充来源偏好。
- 不能作为确定性吉凶规则。
- 联网只用于公开号段、归属地或可得性线索。
- 不抓私人信息。
- 不自动购买号码。
- 不承诺真实库存。

## 候选生成流程

1. 确认选号目标。
2. 确认 `bazi_yongshen`。
3. 确认性别、年龄、职业、阶段。
4. 确定尾数五行。
5. 确定职业动态组合。
6. 设计尾四/尾五。
7. 用固定规则自检。
8. 标注风险。
9. 如用户授权，可查公开可得性线索。
10. 输出候选和边界说明。
