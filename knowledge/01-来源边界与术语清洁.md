# 来源边界与术语清洁

## 来源边界

本知识库只整理手机号码数字能量相关内容。

纳入：

- 手机号码后八位。
- 两位数组合。
- 三数组局。
- 尾数、尾二、尾三、尾四。
- 0 和 5。
- 伏位。
- 选号禁忌。
- 人群匹配。
- 八字喜用神对选号尾数的影响。
- 联网查询公开号段/归属地/可得性线索的边界。

不展开：

- 独立八字排盘。
- 风水宅局。
- 面相手相。
- 医疗诊断。
- 投资预测。
- 婚姻判决。

## 术语统一

| 原始表达 | 统一表达 |
|---|---|
| 天一 | 天医 |
| 七星 | 八星/七星磁场，含天医、生气、延年、绝命、五鬼、六煞、祸害、伏位 |
| 断吉凶 | 结构观察 / 体系内倾向判断 |
| 凶星 | 风险/动态能量，不等于绝对坏 |
| 吉星 | 静态/稳定能量，不等于绝对好 |
| 血光、病灾 | 压力、作息、意外风险、身体管理提醒 |
| 离婚、婚外情 | 关系张力、边界风险、沟通失衡提醒 |
| 破财、亏钱 | 财务压力、现金流风险、投资纪律提醒 |
| 一定、必然、铁口直断 | 在体系内可能呈现 / 倾向于 / 需要留意 |

## 强断言降格原则

原始材料里有很多强烈表达，进入智能体知识库时统一降格。

| 原始强口径 | 智能体口径 |
|---|---|
| 这个号码一定破财 | 这个结构在体系里提示现金流压力或财务纪律风险 |
| 一定离婚 | 这个结构提示关系张力和沟通边界风险 |
| 一定有病灾 | 这个结构提示作息、压力和身体管理需要关注 |
| 换号就翻身 | 换号只是辅助匹配，真正变化仍来自行动 |
| 凶星必凶 | 凶星有可用面，关键看位置、数量和后续承接 |
| 吉星必吉 | 吉星过多或没有动态承接也可能无效 |
| 女人禁止大延年 | 女性、女孩、老人或高压人群慎用大延年 |
| 两个大天医两段婚姻 | 大天医重复可能提示关系/财务主题失衡，不做婚姻判决 |

## 判断等级

| 等级 | 可说 | 不可说 |
|---|---|---|
| 结构事实 | 后八位拆出 7 个两数组，尾三为某组合 | 编造未出现的组合 |
| 体系倾向 | 这个结构偏向表达、投资、管理、贵人等主题 | 这个人一定发生某事 |
| 匹配建议 | 这个号码与当前职业/阶段匹配或不匹配 | 这个号码决定命运 |
| 行动建议 | 关注现金流、沟通、作息、节奏、家庭边界 | 代替专业意见 |
