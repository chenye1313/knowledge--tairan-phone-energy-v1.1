# 人群场景与需求匹配

## 总原则

号码不是越吉越好，而是要匹配人、职业、阶段和需求。

同一个号码结构，对不同人群的含义不同。

## 老板/创业者

核心需求：

- 事业责任。
- 管理团队。
- 现金流。
- 投资纪律。
- 贵人资源。

适合：

- 延年 -> 天医。
- 绝命 -> 天医。
- 生气 -> 天医。
- 小天医递进到大天医。

慎用：

- 凶星连片。
- 大绝命结尾。
- 天医 -> 绝命。
- 祸害结尾。

输出重点：

- 这个号是否支持团队管理。
- 是否支持现金流承接。
- 是否有投资过猛或回收风险。

## 销售/讲师/表达型职业

核心需求：

- 口才。
- 说服力。
- 成交。
- 客户信任。

适合：

- 祸害 -> 天医。
- 祸害 -> 生气。
- 祸害 -> 延年。

慎用：

- 祸害过多。
- 祸害结尾。
- 祸害 -> 绝命/五鬼。

输出重点：

- 表达是否能转成交。
- 口才是否有财库承接。
- 是否容易口舌是非。

## 投资/资产/金融型

核心需求：

- 魄力。
- 风险控制。
- 回收。
- 现金流。

适合：

- 小绝命 -> 大天医。
- 绝命 -> 延年。
- 绝命前后有吉星承接。

慎用：

- 大绝命 -> 小天医。
- 天医 -> 绝命。
- 绝命结尾。
- 绝命连五鬼。

输出重点：

- 投出去能否回收。
- 是否现金流压力大。
- 是否高估目标、忽略路障。

## 创意/教育/策划/研究

核心需求：

- 思考。
- 学习。
- 创意。
- 落地。

适合：

- 五鬼 -> 天医。
- 五鬼 -> 延年。
- 五鬼 -> 生气。

慎用：

- 五鬼过多。
- 五鬼结尾。
- 五鬼连绝命。

输出重点：

- 创意是否能落地。
- 思考是否转成果。
- 是否过度熬夜或焦虑。

## 设计/客服/服务/审美行业

核心需求：

- 人缘。
- 审美。
- 亲和力。
- 服务转化。

适合：

- 六煞 -> 天医。
- 六煞 -> 延年。
- 六煞 -> 生气。

慎用：

- 六煞过多。
- 六煞夹 0/5。
- 已婚人士过多六煞。

输出重点：

- 人缘是否能转成果。
- 情绪和关系边界是否稳定。

## 上班族

核心需求：

- 稳定。
- 工作承接。
- 压力平衡。
- 可存钱。

适合：

- 小天医。
- 小延年。
- 生气。
- 结构稳定、凶星少。

慎用：

- 大绝命。
- 大五鬼。
- 凶星尾部连片。
- 大延年压力过重。

## 女性号主

重点看：

- 大延年是否过重。
- 六煞是否过多。
- 绝命/五鬼是否过大。
- 关系和情绪主题是否被放大。
- 是否有天医/生气/小延年承接。

输出边界：

- 不做婚姻判决。
- 不说“必然离婚/出轨/婚外情”。
- 只说关系张力、角色压力、边界风险。

## 老人

核心需求：

- 平稳。
- 健康管理。
- 家庭和气。
- 少操心。

适合：

- 生气 -> 小延年。
- 小天医辅助。
- 少量六煞/祸害作为人际或表达辅助。

慎用：

- 大延年。
- 大绝命。
- 大五鬼。
- 凶星连片。

## 孩子/学生

核心需求：

- 学习。
- 思考。
- 行动。
- 压力可承受。

适合：

- 小五鬼 -> 小延年。
- 五鬼 -> 延年 -> 生气。
- 生气结尾降低压力。

慎用：

- 大五鬼。
- 大绝命。
- 女孩大延年。
- 持续加压结构。

## 公共号/公司号

判断重点：

- 是否需要表达获客。
- 是否需要服务转化。
- 是否需要现金流承接。
- 是否需要管理团队。

常见组合：

- 销售号：祸害 -> 天医。
- 咨询号：祸害/五鬼 -> 天医。
- 管理号：延年 -> 天医。
- 服务号：六煞 -> 天医。

公共号也不能承诺业绩，只能作为辅助匹配。
