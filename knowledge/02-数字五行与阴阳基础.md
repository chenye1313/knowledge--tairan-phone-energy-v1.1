# 数字五行与阴阳基础

## 后天八卦数字

| 数字 | 卦象/方位 | 五行 | 核心象 | 体系内提醒 |
|---|---|---|---|---|
| 0 | 无卦 | 空/无 | 空、断、隐藏、阻隔 | 选号尽量避 0，尾 0 重点提醒落空风险 |
| 1 | 坎/北 | 水 | 智慧、主见、思考、控制 | 多时可能自我、控制、透支 |
| 2 | 坤/西南 | 土 | 承载、包容、保守、内敛 | 多时可能郁闷、压抑、行动慢 |
| 3 | 震/东 | 木 | 行动、雷厉风行、爆发 | 多时可能急躁、持续力不足 |
| 4 | 巽/东南 | 木 | 思考、学习、风、变化 | 多时可能犹豫、多疑、想多做少 |
| 5 | 中宫 | 土 | 放大、阻碍、变化、延续 | 不单独成卦，结合前后组合判断 |
| 6 | 乾/西北 | 金 | 权力、领导、男主人、责任 | 多时强势、固执、压力 |
| 7 | 兑/西 | 金 | 口才、表达、成交、喜悦 | 多时口舌、反复、好面子 |
| 8 | 艮/东北 | 土 | 稳重、停止、责任、资产 | 多时固执、迟缓、保守 |
| 9 | 离/南 | 火 | 热情、目标、自由、光明 | 多时冒进、好高骛远、易被骗 |

## 阴阳

| 类型 | 数字 | 观察口径 |
|---|---|---|
| 阳数 | 1、3、5、7、9 | 外放、行动、表达、主见、张力 |
| 阴数 | 0、2、4、6、8 | 内敛、承载、稳定、谨慎、保守 |

观察方法：

1. 只看手机号后八位。
2. 统计单数和双数。
3. 女号主后八位阳数过多，提示男性化思维、担当、外放或压力。
4. 男号主后八位阴数过多，提示柔和、犹豫、内收或依赖。
5. 这只是风格观察，不能做人格判决。

## 单数字多寡

| 数字多 | 体系内倾向 |
|---|---|
| 1 多 | 主见强、想法多、控制感强、智慧强 |
| 2 多 | 内敛、保守、踏实、不爱表达 |
| 3 多 | 行动力强、急、效率高、适合销售公关 |
| 4 多 | 学习力强、思考多、谨慎、反复权衡 |
| 5 多 | 变化、阻碍、放大、付出和结果不稳定 |
| 6 多 | 领导力、责任、权威、强势 |
| 7 多 | 表达、口才、成交、外柔内刚 |
| 8 多 | 稳重、责任、资产、固执 |
| 9 多 | 热情、目标感、胆大、乐观、冒进 |

## 尾数识人

尾数是终局，不替代完整组合判断。

| 尾数 | 体系内观察 |
|---|---|
| 0 | 结果处有落空、阻隔、隐藏，需要重点风险提醒 |
| 1 | 智慧、灵活、思考、主见 |
| 2 | 承载、包容、顾及他人、内在委屈 |
| 3 | 行动快、效率高、雷厉风行 |
| 4 | 思考全面、谨慎、学习、犹豫 |
| 5 | 停滞、瓶颈、延续前面磁场 |
| 6 | 权力、领导、责任、事业感 |
| 7 | 口才、表达、沟通、变化 |
| 8 | 稳重、原则、资产、停止 |
| 9 | 热情、活跃、目标、团队气氛 |

## 五行生克

相生：

```text
水生木 -> 木生火 -> 火生土 -> 土生金 -> 金生水
```

相克：

```text
水克火 -> 火克金 -> 金克木 -> 木克土 -> 土克水
```

在选号设计里，五行只用于尾数偏好和结构缓冲；不用于本知识库自行排八字。
