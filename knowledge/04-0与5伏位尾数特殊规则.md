# 0 与 5、伏位、尾数特殊规则

## 0

0 在手机号中不直接进入八星固定组合。

体系内含义：

- 空。
- 断。
- 隐藏。
- 阻隔。
- 落空。

判断方式：

| 位置 | 观察 |
|---|---|
| 中间 0 | 看外层 `A0B` 的 `AB` 是什么星，再加“被阻隔/隐藏/落空” |
| 尾部 0 | 结果处落空，重点提醒现实行动、现金流、关系和健康管理 |
| 号段带 0 | 只作为低权重提醒，不直接判凶 |

示例：

- `109`：外层 `19` 为延年，中间 0 表示主导权、责任或沟通被阻隔。
- `301`：外层 `31` 为天医，中间 0 表示财库或关系主题被阻隔。
- `140`：生气后尾 0，提示机会/贵人关系落空风险。

输出限制：

- 可以说“结果处有落空或阻隔提示”。
- 不可说“万事一场空”作为最终结论。

## 5

5 在手机号中不直接进入八星固定组合。

体系内含义：

- 放大。
- 延续。
- 阻碍。
- 变化。
- 中宫土。

判断方式：

| 位置 | 观察 |
|---|---|
| `A5B` | 看外层 `AB` 是什么星，再加“放大/延续/阻碍” |
| 尾 5 | 延续前面磁场，可能达不到预期 |
| 凶星中夹 5 | 放大凶星，选号应规避 |
| 吉星中夹 5 | 可以谨慎使用，但仍要看整体结构 |

禁忌：

- `158`：外层 `18` 五鬼，被 5 放大。
- `157`：外层 `17` 祸害，被 5 放大。
- `159/951`：外层 `19/91` 大延年夹 5，压力放大，慎用。

## 伏位

伏位组合：

```text
11、22、33、44、66、77、88、99
```

不包括：

```text
00、55
```

判断规则：

1. 伏位本身不单独定吉凶。
2. 它延续前一个磁场。
3. 前面是吉星，伏位可延续吉星。
4. 前面是凶星，伏位会延续风险。
5. 豹子号要看前一组，不按“重复数字天然好”判断。

常见结构：

| 结构 | 体系内提醒 |
|---|---|
| 绝命 + 伏位 | 投资、行动、资产主题重复消耗 |
| 六煞 + 伏位 | 情绪/关系/审美主题反复 |
| 祸害 + 伏位 | 是非、表达、沟通主题反复 |
| 五鬼 + 伏位 | 思考、熬夜、焦虑、创意主题反复 |
| 天医 + 伏位 | 财库/主副业收益延续 |
| 延年 + 伏位 | 能力和压力并存 |
| 生气 + 伏位 | 贵人和机会延续 |

## 尾部权重

来源中有不同说法：

- 尾星约 30%。
- 尾三约 40%。
- 尾四约 60% 或更高。

统一处理：

```text
尾四 > 尾三 > 尾二 > 中段 > 前段
```

不写死评分公式。

## 尾三与尾四

尾三是“事情走向”，尾四是“结果结构”。

例：

- `913`：`91` 延年 -> `13` 天医，能力/管理转财库。
- `413`：`41` 生气 -> `13` 天医，贵人来财。
- `213`：`21` 绝命 -> `13` 天医，投入/行动后有财库承接。
- `312`：`31` 天医 -> `12` 绝命，钱投出去后转风险。
