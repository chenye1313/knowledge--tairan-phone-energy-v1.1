# 三数成象与动态组合

## 基本原则

两位数组是星，三位数组是事情走向。

```text
ABC = AB 的能量 -> BC 的能量
```

判断重点：

- 前一组是起因。
- 后一组是承接。
- 凶星后接吉星，表示风险/动态被承接。
- 吉星后接凶星，表示原本稳定的主题转为风险。
- 尾三最重要，因为它接近结果。

| 延年 -> 天医 | 管理、运营、企业经营 | `913`、`786` | 能力、责任、管理转财富承接 |
| 六煞 -> 天医 | 设计、客服、审美服务 | `168`、`386` | 人缘、审美、服务转收益 |

## 禁忌结构

| 结构 | 处理 |
|---|---|
| 三颗凶星连在一起 | 高风险，选号规避 |
| 五鬼 + 绝命 | 高风险，避免尾部使用 |
| 五鬼 + 五鬼 | 思考/压力/不稳定重复，规避 |
| 祸害结尾 | 是非和表达主题没有承接 |
| 绝命结尾 | 行动、投资、资产主题没有承接 |
| 五鬼结尾 | 思考、压力、创意主题没有落地 |
| 六煞过多结尾 | 关系、情绪、边界主题过重 |
| 天医重复大组合 | 财务/关系主题可能失衡 |
| 大延年重复 | 压力、管控和挑剔放大 |

## 解释模板

```text
这个尾三是【前一星】转【后一星】。
前一星代表起势，后一星代表结果承接。
所以它不是单纯好坏，而是【主题】能否被【结果】接住。
```
