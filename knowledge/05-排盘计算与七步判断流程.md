# 排盘计算与七步判断流程

## 输入

算号观察最少需要：

```text
手机号
```

完整匹配建议增加：

```text
使用时长：
性别：
年龄：
职业：
婚姻/家庭角色：
当前阶段：
当前问题：
想补能力：
使用期间重大变化：
```

选号设计另见 `07-选号设计全规则.md`。

## 排盘前置规则

1. 中国大陆手机号按 11 位处理。
2. 前三位为号段背景，普通算号以后三八位为重点。
3. 后八位生成 7 个两数组。
4. 后八位生成 6 个三数组。
5. 0/5 按特殊规则处理。
6. 尾四、尾三、尾二优先。

## 七步判断流程

### 第一步：了解号主

先问清楚：

- 使用时长。
- 性别。
- 年龄。
- 职业。
- 是否已婚。
- 当前阶段。
- 想解决什么问题。

使用时长很短的号码，不宜做强判断。

### 第二步：分阴阳

只统计后八位：

- 阳数：1、3、5、7、9。
- 阴数：0、2、4、6、8。

输出为风格观察，不做性别刻板判决。

### 第三步：排能量

用固定表或脚本拆解：

```bash
python3 tools/phone_energy_pai_pan.py 13812345678
```

输出应包含：

- 后八位。
- 7 个两数组。
- 6 个三数组。
- 0/5 特殊结构。
- 尾二。
- 尾三。
- 尾四。
- 各星数量。

### 第四步：辨大势

判断整体结构：

| 大势 | 判断 |
|---|---|
| 全是吉星 | 不一定好，可能静态无效，能量激发不足 |
| 全是凶星 | 风险大，但也要看是否有行动、投资、创意等可用面 |
| 凶星连片 | 高风险，尤其尾部三颗星连在一起 |
| 凶星后接吉星 | 有转化机会 |
| 吉星后接凶星 | 可能好事转风险 |
| 尾部有承接 | 结果相对稳 |
| 尾部凶星或 0 | 结果风险要重点提示 |

### 第五步：看重点

看哪颗星最多，作为主磁场。

| 主磁场 | 重点 |
|---|---|
| 天医多 | 财库、善良、正财、关系/财务承接 |
| 生气多 | 贵人、人缘、机会、开朗 |
| 延年多 | 管理、责任、压力、事业 |
| 绝命多 | 魄力、投资、行动、资产 |
| 五鬼多 | 创意、思考、焦虑、熬夜 |
| 六煞多 | 人缘、审美、情绪、关系 |
| 祸害多 | 口才、表达、销售、是非 |
| 伏位多 | 重复、延续、卡住或持续 |

### 第六步：找缺陷

看缺什么星，判断需求缺口。

| 缺失 | 体系内提醒 |
|---|---|
| 缺天医 | 财库/稳定收入/财务承接不足 |
| 缺生气 | 贵人、人缘、资源支持不足 |
| 缺延年 | 责任、管理、抗压、专业承接不足 |
| 缺绝命 | 行动、魄力、投资/资产动作不足 |
| 缺五鬼 | 创意、策略、思考、学习不足 |
| 缺六煞 | 人缘、亲和、审美、关系柔度不足 |
| 缺祸害 | 表达、成交、说服、口才不足 |

缺失不是人格缺陷，只是体系内需求入口。

### 第七步：抓需求

把号码结构落回号主现实需求：

| 人群 | 核心需求 |
|---|---|
| 老板/创业者 | 管理、现金流、投资纪律、贵人、团队 |
| 销售/讲师 | 表达、成交、客户信任、财库承接 |
| 投资/资产 | 魄力、风险控制、回收、现金流 |
| 上班族 | 稳定、压力平衡、收入承接、人际 |
| 老人 | 健康稳定、家庭和睦、少操心 |
| 孩子/学生 | 学习、思考、行动、压力不过载 |
| 女性高压人群 | 关系、情绪、压力、角色平衡 |

## 输出顺序

```markdown
## 号码结构
## 后八位排盘
## 主磁场
## 尾部结果
## 结构优势
## 结构风险
## 与号主需求的匹配
## 现实行动建议
## 边界说明
```
