# 案例与口径母版 v1

## 1. 为什么需要案例母版

泰然老师材料里有大量故事、案例、金句和课程表达。如果不先分类，后续写书会出现两个问题：

1. 案例压过概念，章节变成故事堆叠。
2. 概念脱离案例，章节变成空泛道理。

案例母版的任务，是让案例服务知识结构。

## 2. 案例分类

| 类型 | 说明 | 典型用途 |
|---|---|---|
| 人物源起案例 | 泰然老师自己的生命事件 | 第0本、总论、方法卷开篇 |
| 学员转化案例 | 学员情绪、财富、婚恋、亲子等问题 | 方法卷、个人卷 |
| 家庭治理案例 | 家族理事会、家族年会、父母、祖先、孩子教育 | 家庭卷 |
| 环境调整案例 | 家宅、办公室、靠山、明堂、空间秩序 | 环境卷 |
| 号码案例 | 手机号组合、数字磁场、辅助优化 | 第五卷附属专题 |
| 文化解释案例 | 易经、儒释道、历史人物、经典句子 | 总论和方法辅助 |

## 4. 金句处理规则

金句不能只按好听程度收录，要按功能分类：

| 金句功能 | 用途 |
|---|---|
| 定义型 | 解释核心概念 |
| 转折型 | 章节开头或结尾 |
| 情绪型 | 增强人物和现场感 |
| 方法型 | 做成练习提示 |
| 边界型 | 防止误读 |

## 6. 边界

- 不把私人痛苦消费化。
- 不把课程包装当成事实原貌。
- 不把个案写成普遍规律。
- 不把风水、号码案例写成确定性承诺。
- 不写未经核对的具体金额、日期、地点和人物关系。
